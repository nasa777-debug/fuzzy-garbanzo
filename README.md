# India Web Usage Analysis Platform

A full-stack web application that analyzes website usage trends, categorizes websites based on risk levels, and visualizes data through an interactive dashboard.

## Features

- User Login Interface
- Website Usage Analysis
- Risk Level Classification
- Interactive Charts and Graphs
- Top Websites Dashboard
- Government Report Submission Simulation
- Responsive User Interface

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- Recharts

### Backend
- Spring Boot
- Java 17
- Maven

## Project Structure

```text
frontend/
backend/
README.md
```

## Run the Project

### Backend

```bash
cd backend
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
